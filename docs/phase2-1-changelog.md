# Phase 2.1 — Unified scrolling proposal

## Routes

- **Single client route:** `#/proposal` with query deep links, e.g. `#/proposal?section=investicia` or `#/proposal?section=dekoracia&sub=dekor-foto`.
- **Legacy redirects:** `#/proposal/dekoracija`, `#/proposal/alternativi`, `#/proposal/investicii` → equivalent `?section=` on load (replace, no nested `#`).

## Navigation

- Desktop: sticky left sidebar (`ProposalSidebar`) with collapsible decoration subsections; `IntersectionObserver` active section (`useScrollSpy`); `scroll-margin-top` on sections.
- Mobile: sticky `<select>` section picker (`ProposalMobileNav`).
- Header: ПРЕЖИВЯВАНЕТО | ПРЕДЛОЖЕНИЕТО | КОНТАКТ + PDF download (`ProposalSiteHeader`).
